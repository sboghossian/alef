Welcome to Alef

Every Claude Code session on this Mac, in one place.

  1. Every city is a project folder, every house is a Claude session. Cars driving around are agents working right now.
  2. Five places up top: Now, World, Work, Mind and System (keys 1–5); each opens the view you last used there, and its other views sit beside it. Click a house to step into that agent's room.
  3. The Feed on the right is everything happening, live: activity, Jev's results, reports, and permission requests you can approve right there.
  4. Press ⌘K to find anything (a view, a vault section, a project, a person, a note), or type a task in the prompt box to start a new session. F is focus mode, H hides every panel.

Press ? any time for the map legend and every shortcut.

Click a note on the pinboard to open the project · the shelf holds the skills it used · Esc to leave
